# Timer sound variations

Each variation contains three mono MP3 cues:

- `*-30-second.mp3` — warning played at each positive 30-second boundary
- `*-tick.mp3` — short cue reused once per second from 10 through 1
- `*-time-up.mp3` — final cue at 00:00

| Variation | Character |
| --- | --- |
| `classic-game-show` | Familiar bells, wooden tick, and three-part buzzer |
| `cinematic` | Sub-bass impact, heartbeat tick, and descending trailer-style hit |
| `mechanical-clock` | Clock chimes, escapement click, and alarm bell |
| `electronic` | Digital warning tones, synth blip, and descending sequence |
| `ominous` | Low gong, metallic heartbeat, and dissonant horror sting |

The files are original synthesized sounds encoded as 44.1 kHz, 128 kbps MP3s.
